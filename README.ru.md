# GYMNOTE

[English](README.md) · **Русский**

> Локальный дневник тренировок на Vue 3: программы, упражнения, подходы и история прогресса без обязательного аккаунта и сервера.

GYMNOTE помогает быстро начать тренировку, записывать фактический вес и повторения, а также запускать заранее подготовленные тренировочные дни из импортированной программы. Данные хранятся локально в браузере и остаются доступны после перезагрузки страницы.

## Возможности

- Свободная тренировка с ручным добавлением упражнений.
- Тренировочные программы с несколькими днями.
- Импорт программ из версионированного JSON-файла.
- Автоматическое заполнение упражнений выбранного дня.
- Плановые подходы, повторения, диапазоны повторений и длительность.
- Запись, редактирование и мягкое удаление выполненных подходов.
- Подходы двух типов: вес + повторения и длительность в секундах.
- Таймер активной тренировки.
- История с длительностью, количеством упражнений, подходов и объёмом.
- Русская и английская локализация с сохранением выбранного языка.
- Адаптивный интерфейс для телефона и десктопа.
- Локальное хранение в IndexedDB с версионируемыми миграциями.

## Архитектура

```text
src/
├── components/       Vue-компоненты интерфейса
├── composables/      Реактивные сценарии приложения
├── domain/           Типы, правила, аналитика и преобразования
│   ├── exercise/
│   ├── program/
│   └── workout/
├── infrastructure/   Dexie и реализации репозиториев
├── repositories/     Независимые от базы контракты
├── locales/          Типизированные переводы RU/EN
├── App.vue
└── main.ts
```

```text
Vue-компонент → composable → интерфейс репозитория → Dexie → IndexedDB
```

Компоненты не обращаются к базе напрямую. Это упрощает тестирование и позволяет позднее заменить хранилище без переписывания интерфейса.

## Запуск

Требуется Node.js `22.18+` или `24.12+` и npm. Версия для NVM зафиксирована в `.nvmrc`.

```bash
nvm use
npm install
npm run dev
```

## Команды

```bash
npm run dev         # сервер разработки
npm run type-check  # проверка TypeScript и Vue
npm run lint        # Oxlint + ESLint
npm run format      # форматирование
npm run build       # проверка типов и production-сборка
npm run preview     # просмотр production-сборки
```

## Импорт программы

Нажмите **«Импортировать программу»** и выберите JSON-файл формата GYMNOTE. Готовый пример:

- [`public/examples/my-three-day-gym-program.json`](public/examples/my-three-day-gym-program.json)

```json
{
  "format": "gymnote-training-programs",
  "version": 1,
  "programs": [
    {
      "name": "Программа на три дня",
      "days": [
        {
          "name": "День 1",
          "exercises": [
            {
              "exerciseId": "system:bench-press",
              "targetSets": 4,
              "targetRepetitionsMin": 8,
              "targetRepetitionsMax": 10,
              "targetDurationSeconds": null
            }
          ]
        }
      ]
    }
  ]
}
```

Для упражнения по времени повторения должны быть `null`:

```json
{
  "exerciseId": "system:plank",
  "targetSets": 3,
  "targetRepetitionsMin": null,
  "targetRepetitionsMax": null,
  "targetDurationSeconds": 40
}
```

Импорт проходит runtime-валидацию: проверяются формат, версия, структура, числовые ограничения и наличие упражнений в каталоге. UUID и даты создаёт само приложение.

## Хранение и миграции

Тренировки и программы сохраняются локально в IndexedDB. Dexie управляет версиями схемы и миграциями старых данных. Изменение TypeScript-типа не обновляет существующие записи браузера автоматически, поэтому миграции являются частью модели данных.

## Принципы проекта

- Local-first: основные сценарии не требуют сервера.
- Mobile-first: интерфейс рассчитан прежде всего на использование в зале с телефона.
- План и факт разделены: программа хранит назначение, тренировка — выполненные подходы.
- История хранит снимок программы и дня.
- Удаление подходов выполняется мягко через `deletedAt`.
- Внешние данные считаются недоверенными и проверяются во время выполнения.
